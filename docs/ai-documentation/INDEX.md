# AI Documentation Zone

How to write documentation for AI agents working in this repository. Read this zone before creating or editing any file under `docs/` or `CLAUDE.md`.

## When to read this zone

- You are about to create a new doc in `docs/`
- You are updating an existing doc and want to keep it consistent
- You finished a task and the post-change checklist says "update docs"

## When NOT to read this zone

- You are writing code comments or commit messages — follow the surrounding code style instead
- You are writing user-facing text (bot messages, errors) — those are in Russian and live in code

## Files

| File                         | What it covers                                                      |
| ---------------------------- | ------------------------------------------------------------------- |
| [structure.md](structure.md) | Mandatory doc skeleton, file naming, length targets, the INDEX rule |
| [style.md](style.md)         | Tone and voice: imperative, low-fluff, no history, no marketing     |

## The one rule that keeps this system alive

Every new doc MUST get a one-line entry in its zone's `INDEX.md`. A doc that is not linked from an INDEX does not exist for future agents.
